# Local model files

Nothing here is bundled. Supply model files yourself (or import them in the app: Model Center).

- `hand_landmarker.task` — MediaPipe Hand Landmarker (required by Vision, Air Canvas, Gestures, Creative hand input).
- `hf/<org>/<model>/...` — Transformers.js models in Hugging Face repo layout, e.g.
  `hf/Xenova/distilgpt2/config.json`, `tokenizer.json`, `tokenizer_config.json`, `generation_config.json`, `onnx/model_quantized.onnx`.
